📦 Create backup

Backups are generated locally in your browser, not uploaded to another server. The encrypted .whcbackup file contains its salt and IV; keep its password separately. An unencrypted JSON file contains sensitive personal information.

📥 Restore / import

Load a backup created here. Inspect its collection counts before any database changes.

Restoring is not transactional across the whole database. A network failure may leave a partial restore. Overwrite replaces the selected document fields but does not delete documents absent from the backup. No automatic deletion is performed.

🔍 Backup safety

✓ Preserves Firestore document IDs, timestamps, geopoints, references, bytes and nested values.
✓ SHA-256 content checksum verified on import.
✓ Password-based AES-256-GCM encryption with PBKDF2.
✓ Preview and per-collection restore selection.
✓ Cancel between database operations.

Not included: Firebase Authentication users, Storage files, security rules, indexes, undiscovered collections, or undiscovered subcollections. These require separate administrator-managed exports.
